# NOVA Secure Conversation Bridge

This service is the browser-to-Pi conversation gateway for NOVA Voice.

It deliberately supports **conversation + TTS only**. It does not expose shell commands, GPIO, file writes, messaging or account actions to the public website.

## Flow

`voice.universaldragon.com -> NOVA Bridge (8130) -> LLM brain -> Voice Soul v3 (8125) -> WAV reply`

## Security model

- Binds to `127.0.0.1` by default.
- Intended to sit behind a Cloudflare Tunnel + Cloudflare Access policy before any public exposure.
- Browser requests are limited to `NOVA_ALLOWED_ORIGINS`.
- No API keys or bearer tokens are stored in website JavaScript.
- When `NOVA_REQUIRE_CF_ACCESS=1` (default), browser requests must arrive with Cloudflare Access identity headers. A separate `NOVA_BRIDGE_TOKEN` can be used for trusted non-browser clients.
- The bridge reports `executed_action: false` for every chat request.

## Install on Pi 5

```bash
cd ~/universal-dragon-voice-core/nova_bridge
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Required environment

At least one brain provider:

```bash
export GROQ_API_KEY='...'
# or MOONSHOT_API_KEY / OPENAI_API_KEY
```

Voice Soul v3:

```bash
export NOVA_VOICE_URL='http://127.0.0.1:8125'
export NOVA_VOICE_TOKEN='use-the-same-private-token-as-voice-soul-v3'
```

Web origin allowlist:

```bash
export NOVA_ALLOWED_ORIGINS='https://voice.universaldragon.com,https://project28268.websitepublisher.ai'
```

For local-only testing before Cloudflare Access is configured:

```bash
export NOVA_REQUIRE_CF_ACCESS=0
export NOVA_BRIDGE_TOKEN='a-long-random-local-test-token'
```

Do **not** place `NOVA_BRIDGE_TOKEN`, provider keys or `NOVA_VOICE_TOKEN` in the public website.

## Run

```bash
.venv/bin/python3 bridge.py
```

Default bind: `127.0.0.1:8130`.

Health check:

```bash
curl http://127.0.0.1:8130/healthz
```

## API

### `POST /v1/chat`

```json
{
  "text": "NOVA, system status explain pannunga",
  "session_id": "optional-browser-session-id",
  "language": "auto",
  "mood": "auto"
}
```

Response:

```json
{
  "ok": true,
  "session_id": "...",
  "reply": "...",
  "brain": "groq",
  "audio_url": "/v1/audio/<id>.wav",
  "voice": {
    "status": "ok",
    "engine": "indicf5",
    "mood": "confident",
    "language": "ta"
  },
  "executed_action": false
}
```

### `GET /v1/audio/<id>.wav`

Short-lived WAV generated by Voice Soul v3. The browser should fetch this URL with credentials and play it as a Blob URL.

## Production boundary

Before connecting the public site:

1. Voice Soul v3 must remain private on localhost.
2. NOVA Bridge must remain private on localhost and be published only through an authenticated tunnel.
3. Configure Cloudflare Access for the bridge hostname.
4. Verify allowed origins.
5. Do not expose action/tool endpoints through this bridge.

A future permission-gated action service should remain a separate component with explicit approval + verification, rather than being added to this conversation endpoint.
